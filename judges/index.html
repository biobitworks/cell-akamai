What we added to the workshop

1 · Problem

Can scientific agents improve an answer at a measurable cost, with evidence someone else can check?

2 · Tech stack

Strands role separation; Akamai vLLM / Qwen3-4B; Python notebooks, tests, commitment checks and aggregate dashboards.

3 · Demo + code

Compare actual local/cloud pilot summaries below; inspect frozen data, strict scoring and failure accounting in the repository.

  • Local + cloud pilots: local Ollama Llama 3.2 3B and Akamai Qwen3-4B through an OpenAI-compatible harness. Different models/hardware; no causal platform advantage claimed.
  • Deterministic data: 32 frozen synthetic ECA tasks; exact original/FCO/FCG reconstruction and hashes. Representations are paired, not independent biological datasets.
  • Agent controls: B0 single call, B1 voting proxy, B2 challenge, B3 randomized control. Different call budgets prevent a compute-matched causal claim.
  • Evidence custody: answer SHA-256 commitments before scoring, configuration/coverage checks, explicit refusal on mismatch and sanitized summaries. Recovered archive commitment discrepancies remain under reconciliation.
  • Measurement corrections: server-usage tokens, not chunks; tokens/s and latency [ms]. Missing values and zero-correct denominators stay unavailable. Independent-repeat error bars are not yet available.
  • Verified successes: real GPU concurrency measurements; a tool-free Strands canary; deterministic reconstruction; local/cloud scored pilots; a short tuning pilot preserving a negative result.

What we established: a reproducible evaluation framework joining frozen ECA records, exact original/FCO/FCG reconstruction, role-separated agent policies, local/cloud pilots and checkable evidence. Our first experiment’s sequential tokens/s² calculations reproduce exactly. A tool-free Strands call reached Akamai successfully, and the dashboard preserves measured outcomes alongside their provenance.
