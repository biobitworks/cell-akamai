## Measurand contract — never conflate units
- `N_completion` = endpoint-validated completion usage (or scoped vLLM generation counter). Chunks != tokens. Unknown usage => null and UNKNOWN.
- `request_avg_tok_s = N_completion / full_request_duration_s`. Distinct from engine aggregate throughput `sum completion_tokens / experiment_wall_s`, and distinct from decode-only rate.
- `inter_request_tok_s2 = (request_avg_tok_s[i]-request_avg_tok_s[i-1])/(request_midpoint_s[i]-request_midpoint_s[i-1])`. Descriptive workload derivative, **not** per-token instantaneous acceleration, quality gain, or scientific learning.
- `TTFC` = first nonempty streamed chunk delay, not server `TTFT`. Label server-native histogram TTFT separately. Queue/KV gauges are sampled time series; zero idle snapshots are not proof there was no KV pressure.
- At every module report accuracy, exact-match/Hamming error/abstention/invalid JSON, total model calls/tokens, tokens per **correct** item, request rate, aggregate throughput, p50/p95 latency, queue/KV pressure, and cost when evidence supports it. Null != 0.
- Quality/efficiency improvement only if exact frozen paired controls, independent scorer, matching evaluation budget, and observed effect with uncertainty support the claim. No weight updates => no self-training claim.
