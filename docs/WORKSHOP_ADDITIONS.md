# What Cell-Akamai added to the workshop

We extended inference lessons with local/cloud evaluation, frozen synthetic tasks, role-separated policies and auditable evidence.

| Addition | Demonstrated scope | Limit |
|---|---|---|
| Local Ollama / Akamai pilots | Saved and scored small Llama 3.2 3B / Qwen3-4B panels | Different models/hardware; no platform causal comparison |
| Frozen original/FCO/FCG data | 32 tasks reconstruct exactly with matching hashes | Paired synthetic representations, not independent biological data |
| B0–B3 policies | Single call, voting proxy, challenge, randomized control | Unequal call budgets; Genesis proxy, no weight updates |
| Commitment/scoring checks | Refuse changed answers/config/coverage | Recovered archive answer-commitment discrepancies require reconciliation |
| Correct units | Usage-based tokens/s; latency in ms; explicit missing/undefined values | tokens/s² is a rate derivative, not new science; no independent-repeat CI |
| Strands compatibility | Successful tool-free Akamai canary | Full tool workflow/deployment not verified |
| Tests and negative findings | Strict parser, failure accounting, coverage/commitment/dashboard tests; M08 short pilot | Software tests are not GPU evidence; no demonstrated M08 benefit |

No verified training, scientific quality gain, completed hour-scale study or complete project MMR integration is claimed. Anticube and delta G* are NOT_COMPUTED.
